#  Exam Solutions - ΗΜΜΥ ΕΜΠ

Συλλογή θεμάτων και εγκεκριμένων λύσεων εξεταστικών για τα μαθήματα του Τμήματος ΗΜΜΥ ΕΜΠ. Συντηρείται από την Ομάδα Επίλυσης Θεμάτων.

## 📂 Δομή Φακέλων
Τα αρχεία είναι οργανωμένα ως εξής:
`εξάμηνο/μάθημα/έτος/περίοδος/`

Παράδειγμα:
`1ο_Εξάμηνο/Γραμμική_Άλγεβρα/2025/ΚΑΝ/`

Μέσα σε κάθε φάκελο περιλαμβάνονται:
* `thema.pdf` -> Εκφώνηση θεμάτων
* `lysi.pdf` -> Αναλυτική λύση

## 🤝 Πώς να συνεισφέρετε
1. Κάντε clone ή φτιάξτε ένα νέο branch.
2. Προσθέστε τη λύση σας ακολουθώντας την παραπάνω δομή φακέλων.
3. Ανοίξτε ένα **Pull Request** για έλεγχο από τη διαχειριστική ομάδα.
